Présentation du jeu

Le tertre fistule est un prototype de jeu vidéo sonore au tour par tour, jouable au clavier, avec une ambiance d'exploration de donjon.

Le système reprend, sous une forme allégée, les règles de Pathfinder 1 pour un guerrier pouvant atteindre le niveau 6. Il faudra combattre des adversaires, ramasser des objets et briser une porte ; quelques secrets bien cachés rapportent aussi de précieux points d'expérience, utiles face au boss final.

Le projet met l’accent sur les sons, la stéréo, les annonces vocales et une interface graphique synthétique, afin de proposer une expérience accessible aussi bien aux joueurs voyants que non-voyants.

Mode d'emploi

Dans l'écran de jeu

  • Flèches directionnelles (haut, bas, gauche, droite) : déplacement du personnage, avec changement de salle si possible.
  • Tab : sélectionner un élément dans la salle, joueur compris.
  • Entrée : interagir avec l'élément sélectionné (ramasser un objet, ouvrir la fiche de personnage, combattre un monstre, forcer une porte, prendre la sortie).
  • D : décrire vocalement l'élément sélectionné.
  • O : ouvrir les options sonores.
  • Échap : quitter la fiche de personnage ou les options sonores.

Dans l'écran des options sonores

  • Flèches haut / bas : changer de paramètre.
  • Flèches gauche / droite : modifier le paramètre sélectionné.
  • Entrée sur « Valider » : enregistrer les modifications.
  • Entrée sur « Annuler » ou Échap : quitter les options sonores sans enregistrer.
