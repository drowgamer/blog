Présentation du jeu

Accessible Arena Strike est un jeu vidéo sonore en temps réel, jouable au clavier, avec une ambiance de combat d'arène antique.

Le projet met l’accent sur les sons, la stéréo, les annonces vocales et une interface graphique synthétique, afin de proposer une expérience accessible aussi bien aux joueurs voyants que non-voyants.

Mode d'emploi

Dans l'écran de jeu

  • Flèches directionnelles : attaquer

Dans l'écran de fin de partie

  • Flèches haut/bas : sélectionner une option du menu
  • Entrée : valider (rejouer ou quitter)
  • S : consulter les scores
  • Maj + S : consulter vos statistiques
  • H : annoncer un récapitulatif des touches
  • Alt + F4 : quitter le jeu
